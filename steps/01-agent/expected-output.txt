$ kubectl apply -f steps/01-agent/workload.yaml && sleep 2 && kubectl wait --for=condition=Ready workloaddeployment/toolbox-agent

# No instruction in the prompt: the model answers in text
$ curl -s -H 'Host: agent.localhost' http://127.0.0.1:18180/ -d 'hello'
[user] hello
[model] Hello! I am the workshop agent running a scripted model. Ask me to run curl, sqlite or gh, for example "list the talks in sqlite" or "curl -s http://api.workshop-sites.svc/data".

# The model asks for curl; the slot holds the placeholder, which says so
$ curl -s -H 'Host: agent.localhost' http://127.0.0.1:18180/ -d 'fetch http://api.workshop-sites.svc/data'
[user] fetch http://api.workshop-sites.svc/data
[model] call curl({"arguments":"-s http://api.workshop-sites.svc/data"})
[tool curl] error: {"other":"the curl tool isn't installed yet"}
[model] Done. Here is what each step returned: curl: ERROR: {"other":"the curl tool isn't installed yet"}

# Two instructions: the model follows both, and doesn't retry an error
$ curl -s -H 'Host: agent.localhost' http://127.0.0.1:18180/ -d 'fetch http://api.workshop-sites.svc/data. Then sqlite .tables'
[user] fetch http://api.workshop-sites.svc/data. Then sqlite .tables
[model] call curl({"arguments":"-s http://api.workshop-sites.svc/data"})
[tool curl] error: {"other":"the curl tool isn't installed yet"}
[model] call sqlite({"sql":".tables"})
[tool sqlite] error: {"other":"the sqlite tool isn't installed yet"}
[model] Done. Here is what each step returned: curl: ERROR: {"other":"the curl tool isn't installed yet"} | sqlite: ERROR: {"other":"the sqlite tool isn't installed yet"}
